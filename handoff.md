# AI Design Handoff

1. Use HalloBasis as the primary reference for typography, minimalism, whitespace, and playful interactions. Use Mogutable as the primary reference for visual hierarchy, with imagery receiving more emphasis than text.
2. Use Oswald for all page headings and major titles.
3. Use Source Sans Pro for all subheadings, navigation, descriptions, captions, and body text.
4. Make headings large, bold, and visually dominant. Hero headings should use a size of 72-120px on desktop and 48-64px on mobile. Line height should remain between 0.9 and 1.0.
5. Use a three-color system only: Background #FAF7F2, Text #2B211B, Accent #E8A8B8.
6. Use the accent color for links, borders, button fills, hover states, and small decorative graphics and ambient background effects.
7. Maintain strong contrast between text and background. Never introduce additional accent colors.
8. On laptop screens (1024px and wider), use a 2-column layout.
9. On phone screens (768px and below), collapse to 1 column.
10. Keep a maximum content width of 1200px and center the layout horizontally.
11. Use generous whitespace: 96px section spacing, 32px component spacing, and 16-24px text spacing.
12. The hero image should run full width across the top portion of the page and act as the primary focal point.
13. Position the user's name prominently within the hero section and align it with the primary heading structure.
14. Prioritize hierarchy: hero image, name/title, assignment links, supporting text.
15. Style assignment links as filled buttons.
16. Buttons should use the accent color, espresso brown text, 16px border radius, 14px 24px padding, and a minimum height of 48px.
17. On hover, buttons should lift upward by 4px, increase shadow slightly, and animate over 300ms ease-out.
18. Use subtle motion throughout the page.
19. Add a moving background consisting of ambient twinkles.
20. Animate background twinkles using slow fade-in and fade-out cycles.
21. Set twinkle animation speed between 4 and 8 seconds with randomized delays.
22. Keep the moving background decorative only.
23. Use subtle cursor-driven interactions inspired by HalloBasis when appropriate.
24. Maintain a minimal aesthetic. Avoid unnecessary graphics, excessive shadows, gradients, clutter, or decorative effects.
25. Every design decision should reinforce: Cozy, Playful, Minimal, Editorial, Warm, Approachable.
26. When building or editing the page, preserve all existing typography, color, layout, button, and background rules unless explicitly instructed otherwise.
